# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately rather than in a public issue. Include the
version, your platform, steps to reproduce, and the impact you observed. Do not include real API
keys in the report; redact them first.

Areas of particular interest: credential handling, workspace escape, command classification and
execution, approval bypass, and secret leakage into logs or reports.

## Supported versions

Only the latest release receives security fixes during the 0.x series.
